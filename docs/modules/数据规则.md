# 数据规则
## 负责人/版本/基线
负责人：B；版本v1；基线main分支

## 数据边界
1. 预算**不包含往返成都大交通**
2. 非成都城市不能复用成都价格做精确预算
3. 大部分价格为教学估算，标记“未核实”

## 天气状态表
|条件|status|daily长度|summary|联网/模拟|用户提示|
|---|---|---|---|---|---|
|城市=成都 mock模拟|ok|2|模拟：第2天会下雨|模拟|注意第二天有降雨，会替换室内活动|
|日期超查询区间|out_of_range|0|查询日期超出支持范围|模拟|无法获取该时间段天气|
|非成都城市输入|error/city_not_found|0|无法查询该城市天气|模拟|暂不支持该城市天气查询|

## 规则决策顺序
1. 老人行程强度限制
2. 雨天自动替换室内备选活动
3. 室内候选不足兜底处理
4. 防止跨天重复活动
5. 预算判定，判断是否超支

## 费用公式
总费用 = 住宿费 + 餐饮费 + 市内交通费 + 门票总和 + 机动费
住宿费 = 酒店单价 × 住宿晚数
餐饮费 = 单人餐费 × 人数 × 总天数
市内交通费 = 单日交通价 × 总天数

## 边界与失败处理
- 天气报错：提示用户暂不支持该城市/超出查询时间
- 预算超支：返回within_budget=False
- 雨天：自动替换户外景点为室内备选
