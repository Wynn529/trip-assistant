# 预算复算.md
## 场景1 用户预算3000元
输入请求：3天行程，2人，预算3000，无老人，无雨天
所选活动/酒店：成都示例酒店
住宿=单价×晚数：320 * 2 =640
餐饮=单价×人数×天数：60 *2 *3 =360
市内交通=单价×天数：80*3=240
门票逐活动单价×人数：0
机动费用：150
分项合计： 640+360+240+0+150 =1390
程序总额：1390
预算差：1610
是否满足：True
证据：planner.py直接调用返回结果
